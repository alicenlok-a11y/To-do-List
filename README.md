# Simple Todo App

A clean and interactive Todo application that allows users to create, complete, and delete tasks with optional due dates. The project focuses on modular JavaScript architecture and client-side form validation.

## Functionality

Add new todos using a popup form

Optionally assign a due date to each task

Mark tasks as completed using a checkbox

Delete tasks from the list

View preloaded initial tasks on page load

See real-time form validation feedback before submission

## Technology

Object-Oriented Programming (OOP)

ES6 module imports/exports

Dynamic element creation using <template>

Custom form validation logic

State synchronization between UI and data
